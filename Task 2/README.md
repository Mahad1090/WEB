# Task 2 - Archery Game

An interactive browser-based archery game built with HTML5, CSS3, and JavaScript, featuring real-time scoring and gameplay mechanics.

## Project Overview

Archery Game is a fun, interactive web game where players test their archery skills by hitting moving targets within a time limit. The game features dynamic target movement, score tracking, and a countdown timer for exciting gameplay.

## Game Features

### Core Gameplay
✅ **Target System** - Dynamically moving targets that players must hit  
✅ **Score Tracking** - Real-time score display and hit/miss tracking  
✅ **Timer** - Countdown timer for time-limited gameplay  
✅ **Arrow Mechanics** - Interactive arrow shooting with visual feedback  
✅ **Hit Detection** - Collision detection between arrows and targets  
✅ **Visual Feedback** - Animations and visual effects for hits/misses  

### User Interface
- **Header Section** - Score display and timer display
- **Game Container** - Main gameplay area with target zone
- **Responsive Layout** - Works on desktop, tablet, and mobile devices
- **Visual Feedback** - Clear indication of hits and misses

## Technologies Used

- **HTML5** - Semantic structure and canvas elements
- **CSS3** - Responsive layout, gradients, and animations
- **JavaScript** - Game logic, physics, and event handling
- **Canvas API** - Graphics rendering and game objects
- **CSS Flexbox** - Responsive header layout

## Game Mechanics

### Starting the Game
1. Player opens the game page
2. Game area is displayed with a target
3. Timer and score initialized

### Gameplay
- Player aims and shoots arrows at the target
- Each successful hit increases the score
- Target moves to prevent easy hits
- Timer counts down during gameplay
- Game ends when timer reaches zero

### Scoring System
- Points awarded for each successful hit
- Hit count displayed in real-time
- Final score shown at game end
- Potential for high score tracking

## How to Play

1. Open `archery.html` in a web browser
2. Wait for the game to start
3. Click or tap to shoot arrows at the target
4. Try to hit the moving target as many times as possible
5. Beat the timer to get the highest score
6. Improve your accuracy and reaction time
