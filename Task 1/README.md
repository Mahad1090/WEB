# Task 1 - Mahad Art Gallery Website

A responsive HTML/CSS art gallery website showcasing paintings and providing information about the gallery.

## Project Overview

Mahad Art Gallery is a multi-page website dedicated to showcasing fine art and providing information about the gallery, including its mission, team, and feedback system.

## Pages Included

### 1. **task1.html** - Main Gallery Page
- Hero section with gallery branding
- Featured artworks grid showcase
- Gallery introduction and welcome message
- Responsive image gallery
- Integration with Font Awesome and Material Icons

### 2. **task1-2.html** - About Us Page
- Gallery history and mission statement
- Team member profiles (Mahad Khan, Sarah Ahmed, Ali Hassan)
- Services offered (exhibitions, workshops, consultations)
- Gallery operating hours
- Professional business information

### 3. **task1-3.html** - Feedback Page
- User feedback and contact form
- Multiple input options (name, email, message, rating)
- Form submission functionality
- Subject category selection
- Message composition area

## Technical Stack

- **HTML5** - Semantic markup and structure
- **CSS3** - Responsive design, flexbox, grid layout
- **Icons** - Font Awesome (v6.5.1) and Google Material Icons
- **Meta Tags** - SEO optimization with descriptions and keywords

## Key Features

✅ Responsive Design - Optimized for desktop, tablet, and mobile devices  
✅ Modern UI - Professional gradient backgrounds and hover effects  
✅ Semantic HTML - Proper use of HTML5 semantic elements  
✅ Image Gallery - Grid-based gallery with image display  
✅ Contact Form - Functional feedback form with multiple input types  
✅ Navigation Menu - Smooth scroll navigation with active states  
✅ SEO Friendly - Meta tags for search engine optimization  

## Design Highlights

- Clean and modern aesthetic with professional color scheme
- Smooth transitions and hover effects on interactive elements
- Mobile-first responsive design approach
- Accessibility-friendly markup and navigation
- Professional typography and spacing
